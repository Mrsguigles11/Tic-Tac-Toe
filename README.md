# Tic-Tac-Toe

This is a naughts and crosses game created for The Odin Poject to be played in the browser, with 1 player against the computer. The project is designed to demonstrate skills writing JS code using factory functions and the modular pattern.

Skills demonstrated:
 - HTML
 - CSS
 - Javascript(modular pattern)
